# 看板核心交互

## 目标

验证用户在一个完整看板会话中，可以切换标的、切换周期和范围、修改均线、控制 MA 图例，并在 K 线图上完成 hover、滚轮缩放和水平拖拽。

## 执行方式

- 使用 `@chrome` 插件控制真实 Chrome 页面执行。
- 不使用 Playwright CLI，不写前端单元测试或组件测试。
- 交互验证优先使用可见文本、控件选中态、Chrome 截图和控制台错误。
- K 线图是否有效渲染以真实截图为准；不要求通过测试脚本读取 canvas 像素。
- 页面上的行情数值、数据范围日期和数据行数不是固定值，只校验存在且格式正确。
- 摘要区数值只要求是有效数字或百分比；K 线卡片右上角只要求匹配 `cache|refreshed · 正整数 条`。
- 周期和范围分段控件建议按 `.ant-segmented-item` 的精确文本点击，并在每次点击后读取 `.ant-segmented-item-selected` 确认选中态。
- K 线 hover、缩放、拖拽建议先读取 canvas 的 `getBoundingClientRect()`，再使用相对坐标命中绘图区，避免不同 Chrome 窗口尺寸导致固定坐标失效。

## 前置条件

- 已完成“加载、刷新与缓存”链路。
- 当前页面标题为 `ETF Dashboard`。
- 当前默认标的是 `红利低波100 · 930955.CSI`。
- 当前范围建议保持 `全部`，保证有足够数据进行缩放和平移。

## 操作步骤

### 标的切换

1. 点击 `标的` 下拉框。
2. 选择 `中证红利质量 932315.CSI`。
3. 等待标题下方的当前标的变为 `中证红利质量 · 932315.CSI`。
4. 检查摘要区、数据范围和 K 线卡片右上角状态。
5. 通过 Chrome 截图确认 K 线图已重新渲染。
6. 再次打开 `标的` 下拉框，切回 `红利低波100 930955.CSI`。
7. 等待标题下方的当前标的变为 `红利低波100 · 930955.CSI`。
8. 再次检查摘要区、数据范围、缓存状态和 K 线截图。

### 周期与范围切换

1. 在 `周期` 分段控件中依次点击 `周`、`月`、`季`、`年`、`日`。
2. 每次点击后等待对应按钮处于选中态。
3. 每次点击后通过页面可见状态或截图确认 K 线区域仍正常显示。
4. 在 `范围` 分段控件中依次点击 `近一年`、`近三年`、`近五年`、`近十年`、`全部`。
5. 每次点击后等待对应按钮处于选中态。
6. 每次点击后检查页面没有空数据提示和加载失败提示。
7. 检查控制台没有 error 级别应用错误。

### 均线与图例

1. 定位 `均线` 输入框。
2. 将内容从 `5 8 13 21 34 55` 改为 `5 20 60`。
3. 等待图例更新。
4. 点击 `MA20` 图例按钮，确认按钮进入隐藏态。
5. 再次点击 `MA20` 图例按钮，确认按钮恢复显示态。
6. 将输入内容改为 `5 5 abc 1000 13`。
7. 等待图例更新。
8. 通过截图确认 K 线图仍正常渲染。

### K 线图交互

1. 读取 canvas 位置和尺寸，确认存在可交互的 K 线绘图区。
2. 将鼠标移动到 K 线绘图区内部。优先使用相对坐标 `x = canvas.x + canvas.width * 0.72`、`y = canvas.y + canvas.height * 0.33`。
3. 如果没有命中 tooltip，再尝试 `0.50 / 0.45` 或 `0.86 / 0.42` 附近的相对坐标。
4. 等待 tooltip 出现。
5. 在绘图区内向上滚动鼠标滚轮，执行放大。
6. 截图确认 K 线区域仍正常渲染，页面没有整页跳动。
7. 按住鼠标左键在绘图区水平拖拽。拖拽前先完成一次滚轮放大，否则全量视图下可能没有可平移空间。
8. 松开鼠标后再次 hover，确认 tooltip 仍可出现。
9. 在绘图区内向下滚动鼠标滚轮，执行缩小。
10. 鼠标移出 K 线区域，确认 tooltip 消失。

## 验收断言

标的切换：

- 切换到 `中证红利质量 932315.CSI` 后，页面显示 `中证红利质量 · 932315.CSI`。
- 数据范围匹配 `YYYY-MM-DD 至 YYYY-MM-DD`。
- K 线卡片右上角显示 `cache · 正整数 条` 或 `refreshed · 正整数 条`。
- 切回 `红利低波100 930955.CSI` 后，页面显示 `红利低波100 · 930955.CSI`。
- 数据范围匹配 `YYYY-MM-DD 至 YYYY-MM-DD`。
- K 线卡片右上角显示 `cache · 正整数 条` 或 `refreshed · 正整数 条`。
- 每次切换后，Chrome 截图中 K 线图都不是空白。
- 控制台无 error 级别应用错误。

周期与范围切换：

- 被点击的周期按钮处于选中态。
- 被点击的范围按钮处于选中态。
- 切换周期或范围后，K 线区域仍正常渲染。
- 摘要区仍显示当前标的的最新收盘、涨跌幅、成交额和数据范围。
- 摘要区最新收盘和成交额显示有效数字，涨跌幅显示有效百分比。
- 数据范围匹配 `YYYY-MM-DD 至 YYYY-MM-DD`。
- 页面不出现 `当前筛选下没有可展示的数据`。
- 页面不出现 `数据加载失败，请确认 etf-service 已启动`。
- 控制台无 error 级别应用错误。

均线与图例：

- 输入 `5 20 60` 后，图例显示 `MA5`、`MA20`、`MA60`。
- 旧图例 `MA8`、`MA13`、`MA21`、`MA34`、`MA55` 不再显示。
- 点击 `MA20` 后，`MA20` 按钮进入隐藏态，样式变淡。
- 再次点击 `MA20` 后恢复显示态。
- 输入 `5 5 abc 1000 13` 后，图例只保留有效且去重后的 `MA5`、`MA13`。
- `abc` 和 `1000` 不生成图例。
- 控制台无 error 级别应用错误。

K 线图交互：

- canvas 存在，且 `getBoundingClientRect()` 返回的宽高大于 `0`。
- hover 后出现 tooltip。
- tooltip 包含日期或日期范围，以及 `开盘`、`最高`、`最低`、`收盘`、`涨跌额`、`成交量`、`成交额`。
- 当前 hover 位置已有 MA 值时，tooltip 显示对应 MA 数值。
- 滚轮缩放后 K 线区域仍正常渲染，页面不发生整页滚动跳动。
- 拖拽平移后 K 线区域仍正常渲染，松开鼠标后可再次 hover 出 tooltip。
- 鼠标移出 K 线区域后 tooltip 消失。
- 全链路控制台无 error 级别应用错误。

## 失败定位

- 下拉框没有两个选项：检查 `/api/securities/list` 响应和初始化入库数据。
- 切换标的后数据范围不变：检查是否触发新的 `/api/market/getDailyBars` 请求。
- 周、月、季、年为空：检查前端聚合逻辑是否收到完整日线数据。
- 切换范围后为空：检查 `getRangeBars` 使用的最后交易日和窗口起点。
- 图例未跟随输入更新：检查 `parseMaPeriods` 和 `KlineChart` 的 `maText` 依赖。
- 输入无效值后报错：检查均线解析是否过滤非正整数、超大值和重复值。
- hover 无 tooltip：检查 hover 坐标是否落在绘图区内，再检查 canvas 坐标换算和 `getVisibleIndexFromX`。
- 滚轮导致页面滚动：检查绘图区内是否调用 `event.preventDefault()`。
- 拖拽无效：先放大到非全量视图；未缩放时可能没有可平移空间。
