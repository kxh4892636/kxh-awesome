- 证据要求：默认页面截图；标题、标的、摘要、K 线状态、canvas 和 MA 图例断言
- 执行记录位置：本文“执行记录”

  Scenario: 用户打开看板并看到默认行情

    Then 浏览器标题为 "ETF Dashboard"

- 状态：passed
- 执行通道：browser
- 入口：`http://localhost:5173`

- 不做范围：不验证代理、DNS 或第三方行情源故障
- 证据要求：停服后的错误态截图、恢复后的默认看板截图和浏览器控制台记录
- 执行记录位置：本文“执行记录”

```gherkin

    Then 默认看板恢复正常且页面不白屏
```
