# 移动端布局

## 目标

验证看板在移动端宽度下仍可使用，控件、摘要和 K 线区域不发生横向溢出、文本重叠或空白渲染。

## 执行方式

- 使用 `@chrome` 插件控制真实 Chrome 页面执行。
- 不使用 Playwright CLI，不写前端单元测试或组件测试。
- 视口使用真实 Chrome 窗口尺寸或 Chrome DevTools 设备模式设置为 `390 x 844`。
- 布局断言以可见页面、截图和 `document.body.scrollWidth <= window.innerWidth` 为准。
- Chrome 普通窗口可能受最小宽度限制；实测可用 Chrome app 窗口或系统窗口调整方式，将内容视口调整到约 `385 x 854` 后再执行。
- 页面上的行情数值、数据范围日期和数据行数不是固定值，只校验存在且格式正确。
- 调整窗口后先刷新页面，并等待 K 线卡片右上角出现 `cache · 正整数 条` 或 `refreshed · 正整数 条`，再检查 K 线图；否则数据尚未完成渲染时可能暂时读不到 canvas。
- K 线区域在移动端通常位于首屏下方，截图建议使用整页截图，或先滚动到 `K 线` 卡片再截图。

## 前置条件

- `etf-service` 已启动并监听 `http://localhost:8080`。
- `etf-dashboard` 已启动并监听 `http://localhost:5173`。
- 默认桌面链路已经可以正常加载。

## 操作步骤

1. 将 Chrome 视口设置为接近 `390 x 844`。实测可接受内容视口为 `385 x 854`。
2. 打开或刷新 `http://localhost:5173`。
3. 等待浏览器标题为 `ETF Dashboard`。
4. 等待页面显示 `ETF K 线看板` 和默认标的 `红利低波100 · 930955.CSI`。
5. 等待 K 线卡片右上角显示 `cache · 正整数 条` 或 `refreshed · 正整数 条`。
6. 检查标题、当前标的、标的下拉、周期、范围、均线输入和刷新按钮。
7. 检查摘要区四个指标。
8. 检查 K 线卡片、K 线图和 MA 图例。
9. 点击 `周`，等待按钮选中并检查 K 线图仍正常显示。
10. 点击 `近一年`，等待按钮选中并检查 K 线图仍正常显示。
11. 读取 `document.body.scrollWidth` 和 `window.innerWidth`。
12. 截图记录移动端页面，重点检查工具栏、摘要卡片、K 线图、MA 图例和 x 轴日期标签。
13. 检查控制台没有 error 级别应用错误。

## 验收断言

- 浏览器标题为 `ETF Dashboard`。
- 页面显示 `ETF K 线看板`。
- `document.body.scrollWidth <= window.innerWidth`。
- 页面无横向滚动条。
- 标题和当前标的信息不重叠。
- 标的下拉、周期、范围、均线输入和刷新按钮均可见且可操作。
- 摘要区四个指标按移动端布局纵向排列或自动换行，不互相覆盖。
- 摘要区最新收盘和成交额显示有效数字，涨跌幅显示有效百分比，数据范围匹配 `YYYY-MM-DD 至 YYYY-MM-DD`。
- Chrome 截图中 K 线图不是空白。
- MA 图例可换行显示，不溢出屏幕。
- K 线图 x 轴日期标签不应严重重叠；如果窄屏下标签拥挤，需要截图记录为视觉问题。
- 点击 `周` 后，`周` 处于选中态。
- 点击 `近一年` 后，`近一年` 处于选中态。
- 页面不出现 `当前筛选下没有可展示的数据`。
- 页面不出现 `数据加载失败，请确认 etf-service 已启动`。
- 控制台无 error 级别应用错误。

## 失败定位

- 有横向溢出：优先检查工具栏最小宽度、卡片内边距和 K 线容器宽度。
- 控件文字挤压：检查分段控件是否需要换行或允许容器内滚动。
- 摘要区重叠：检查移动端 grid 断点和卡片最小宽度。
- K 线图在移动端为空白：检查 resize 后 canvas 尺寸和重绘逻辑。
- 点击周期或范围后页面空白：检查移动端布局是否导致控件事件被遮挡。
