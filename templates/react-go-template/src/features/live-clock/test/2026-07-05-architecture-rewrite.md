# Live Clock 架构重写验收

## 目标

证明 live-clock 功能迁移到 `features/live-clock` 后，用户仍能在首页看到实时更新时间。

## 前置条件

- 前端开发服务器已启动。
- 浏览器打开首页 `/`。
- 视口使用桌面宽度。

## 操作步骤

1. 打开首页。
2. 定位 `dayjs - Current Time` 区块。
3. 记录当前时间文本。
4. 等待超过 1 秒。
5. 再次记录时间文本。

## 验收断言

```gherkin
Scenario: 用户看到实时更新时间
  Given 用户打开首页
  When live-clock 区块加载完成
  Then 页面展示符合 YYYY-MM-DD HH:mm:ss 格式的时间
  And 等待超过 1 秒后，时间文本发生变化
```

## 失败定位

- 如果时间区块不可见，先检查首页是否正确组合 `LiveClockSection`。
- 如果时间格式错误，先检查 `dayjs` 格式化字符串。
- 如果时间不变化，先检查计时器 effect 是否启动和组件是否重新渲染。

## 执行结果

- 执行时间：2026-07-05 01:48。
- 结论：通过。浏览器读取初始时间 `2026-07-05 01:48:24`，等待超过 1 秒后变为 `2026-07-05 01:48:25`，格式符合 `YYYY-MM-DD HH:mm:ss`。
- 遗留问题：无。
